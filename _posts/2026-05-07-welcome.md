Welcome to the official Kings Fraternity website, powered by [Jekyll](https://jekyllrb.com) and hosted on [GitHub Pages](https://pages.github.com).

This site is the home for news, updates, and information about our fraternity. Stay tuned for more content!

## Getting Started

New posts can be added by creating a file in the `_posts` directory following the naming convention:

```
YEAR-MONTH-DAY-title.md
```

For example, this post is located at `_posts/2026-05-07-welcome.md`.
